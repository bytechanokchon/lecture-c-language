# Preprocessor
เป็นขั้นตอนการทำงานที่เกิดขึ้น ก่อนการประมวลผลในชุดคำสั่งหลัก (main())
ซึ่งเป็นคุณสมบัติเฉพาะในภาษา c (ไม่เจอในภาษาอื่น ๆ) ซึ่งช่วยให้นักพัฒนาสามารถพัฒนาโปรแกรมได้ง่ายขึ้น

โดยการใช้งาน จะนำไว้ด้านบนสุดของไฟล์เสมอ โดยใช้สัญลักษณ์ pound (#) ในการประกาศ preprocessor เช่น 
- #include
- #defind
- #ifdef
- #endif
- #else
- #ifndef
