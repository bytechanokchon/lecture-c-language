# Program Structure

    #include <stdio.h>

    int main (void) 
    {
        printf("Hello World");

        return 0;
    }

**main()** เป็นฟังก์ชันแรกของโปรแกรมที่จะถูกเรียกใช้งานของทุกโปรแกรม

**{  }** ถูกเรียกว่า block of code ใช้สำหรับกำหนดว่าด้านในของฟังก์ชันนี้ จะต้องมีขั้นตอนการทำงานอะไรบ้าง

**;** ใช้สำหรับกำหนดว่า ชุดคำสั่งนี้จบแล้ว
