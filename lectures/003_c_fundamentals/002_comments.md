# Comment
คอมเมนท์ใช้สำหรับเขียนคำอธิบายชุดคำสั่งหรือขั้นตอนการทำงานของโปรแกรม ซึ่งทำให้การทำความเข้าใจโปรแกรมทั้งกับตัวเราและเพื่อนร่วมทีมเป็นเรื่องง่าย

<mark>โดยคอมเมนท์จะไม่ถูกสนใจโดยคอมไพเลอร์</mark>

โดยการเขียนคอมเมนท์ สามารถเขียนได้ทั้งแบบ **บรรทัดเดียว** หรือ **หลายบรรทัด**

**ตัวอย่าง (แบบบรรทัดเดียว)**

    // example single line comment

**ตัวอย่าง (แบบหลายบรรทัด)**

    /*
        example
        multiple
        line
        comment
    */

**ตัวอย่างการเขียนจากงานจริง**

    /*
        Written By ByteChanokchon
        Copyright 2025
    */

    /*
    ****************************************
    *This is a very important comment      *
    *So please read this                   *
    ****************************************
    */

    printf("Hello World"); // this line display user message
