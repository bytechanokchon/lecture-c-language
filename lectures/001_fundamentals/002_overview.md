# Overview
C เป็นภาษาโปรแกรมที่รองรับการเขียนในรูปแบบโครงสร้าง เราสามารถเขียนโปรแกรมได้ทุกประเภทในภาษา c

ภาษา C ถูกนำไปใช้งานหลากหลายที่ เช่น
- mini computer
- unix/linux
- mainframe
- compiler ของภาษาอื่น ๆ ส่วนใหญ่ถูกเขียนขึ้นด้วยภาษา C
- embedded system

## คุณสมบัติหลักของภาษา C
- มีประสิทธิภาพ (Efficient)
- พกพาสะดวก (Portable)
- ทรงพลังแต่มีความยืดหยุ่น (Powerful and Flexible)
- Programmer Oriented

### Efficient
ภาษา C มีประสิทธิภาพและสามารถใช้งานอุปกรณ์คอมพิวเตอร์ได้อย่างมีประสิทธิภาพ

### Portable
มีขนาดเล็กกะทัดลัด สามารถพกพาได้สะดวก สามารถทำงานในระบบคอมพิวเตอร์แบบไหนก็ได้

### Powerful and Flexible
- ภาษา C ถูกนำไปสร้างเป็นระบบปฏิบัติการของคอมพิวเตอร์ 
- ใช้สร้างเป็นคอมไพล์เลอร์ให้กับภาษาอื่น ๆ เช่น fortran, perl, python, pascal, logo, basic
- ใช้สร้างโปรแกรมที่แก้ปัญหาทางฟิสิกส์และวิศวกรรม

### Programmer Oriented
- ภาษา C อนุญาติให้โปรแกรมแมอร์สั่งงานอุปกรณ์คอมพิวเตอร์ได้เอง
- อนุญาติให้โปรแกรมเมอร์จัดการ memory ได้ด้วยตังเอง (ภาษาส่วนใหญ่ทำไม่ได้ เช่น java)
- มี community ขนาดใหญ่
