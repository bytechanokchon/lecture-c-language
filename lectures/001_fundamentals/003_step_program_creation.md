# Step C Program creation
มีอยู่ 4 ขั้นตอนหลักในการสร้างโปรแกรมภาษา c
1. Editing
2. Compiling
3. Linking
4. Executing

### Editing
เป็นกระบวนการที่โปรแกรมเมอร์จะเขียนและแก้ไขชุดคำสั่ง

### Compiling
เป็นการตรวจสอบไวยากรณ์และแปรงชุดคำสั่งระดับสูง (c language) ไปเป็นชุดคำสั่งของเครื่อง (instruction)

### Linking
เป็นขั้นตอนที่ ตัว Linker ทำการรวมเอาโค้ดที่คอมไพล์แล้วจากหลายไฟล์ และนำไลบรารีต่าง ๆ มาต่อเข้าด้วยกันจนกลายเป็นไฟล์โปรแกรมสุดท้าย เช่น .exe (Windows) หรือไฟล์ executable บน Linux/Unix

### Executing
เป็นการเรียกใช้โปรแกรมที่ถูกแปรงเป็นภาษาเครื่องแล้ว

### เพิ่มเติม
- ไวยากรณ์ คือ รูปแบบโครงสร้างของชุดคำสั่งที่กำหนด
- การตรวจสอบไวยากรณ์ คือ การตรวจสอบว่าโครงสร้างของชุดคำสั่งเป็นไปตามที่กำหนดหรือไม่
